# 视频会员红包助手 · 平台规则与叠加指南

## 一、各平台红包规则

### 爱奇艺
- **领取条件**：新客首充优惠最大（如月卡/季卡5折起）；老客可领年卡特惠券、联合会员立减券
- **使用门槛**：直降券无门槛，充值对应档位即抵扣；部分券仅限年卡/连续包月
- **有效期**：券码一般7~30天内充值有效，逾期作废，以领取页为准
- **是否可叠加**：优惠券常不与"首单特惠""整点秒杀价"重复

### 腾讯视频
- **领取条件**：新用户首充特惠、老用户续费立减券、联合会员（视频+音乐）礼包
- **使用门槛**：限月卡/季卡/年卡指定档位；部分为"连续包月首月低价"
- **有效期**：券码多为领取后15~30天
- **是否可叠加**：续费券有时与银行卡支付优惠叠加，联合会员套装一般不与单卡券叠加

### 优酷（酷喵）
- **领取条件**：新客首购、老客续费券、88VIP/联合会员绑定用户额外权益
- **使用门槛**：TV端酷喵会员与手机端会员权益不同，注意券适用终端
- **有效期**：券码7~30天
- **是否可叠加**：与88VIP等会员体系权益常互斥，下单前确认

### B站（哔哩哔哩大会员）
- **领取条件**：新客首月特惠、年度大会员折扣券、连续包年优惠
- **使用门槛**：限大会员档位；苹果/安卓支付偶有差异
- **有效期**：券码多为当月有效或领取后30天
- **是否可叠加**：折扣券不与B币抵扣等重复叠加

### 芒果TV
- **领取条件**：新客首充、老客续费券、综艺/剧综联动活动特惠
- **使用门槛**：全屏会员/PC移动会员档位不同，注意是否支持电视端
- **有效期**：券码7~30天
- **是否可叠加**：立减券一般不与整点秒杀价叠加

## 二、红包叠加逻辑

- **叠加顺序**：券码抵扣 → 平台会员档位折扣 → 支付端（银行卡/Apple支付）优惠，先券码后支付
- **年卡最划算**：同力度下年卡折算每月最低，长看剧用户优先年卡券
- **联合会员算账**："视频+音乐+网盘"联合套装比单买便宜，但用不上的权益别为凑单买
- **续费先领券再开通**：直接在App内续费常按原价走，先领券再下单才抵扣

## 三、品类专属知识要点

### 3.1 月卡/季卡/年卡折算（算账核心）
- 同样折扣下，**年卡折算每月最低**，季卡居中，月卡最贵
- 例：年卡5折 = 月均约2.5元月卡价（示例，以各平台实时定价为准）；偶尔看几部剧就别买年卡
- 先估算自己每月看几部剧，再决定档位，别为"划算"囤用不完的会员

### 3.2 自动续费必须主动确认（红线）
- "连续包月/连续包年"会在到期前**自动扣费**，首月低价只是引流
- 开通前务必看清"连续"字样；开通后**立即到App内关闭自动续费**，避免不知情续费
- 苹果用户在"设置-Apple账户-订阅"里取消；安卓在App会员中心或支付渠道(微信/支付宝)代扣管理里关
- 本技能推荐优惠时，**不替用户默认勾选连续包月**，提醒用户主动确认

### 3.3 多设备同时在线限制
- 各平台会员通常限制同时在线设备数（如手机+平板+电脑2~3台，TV端另算），超出会挤下线
- 家庭多人共用一台电视选"支持TV端"的全屏会员；只在手机看选手机端会员即可
- 手机会员≠TV端会员，想看电视要选贵一档的TV/全屏会员

### 3.4 账号共享违规（红线）
- 买卖、共享、租借会员账号**违反平台用户协议**，可能被封号、冻结会员
- 券码一般绑定领取账号使用，别买"共享号""拼车号""合租号"，便宜几天却有封号和被盗风险
- 正规省钱方式是自己领券充自己的账号，或官方家庭/联合会员

## 四、新客与老客区别

- **新客专享**：各平台首充1元/首月低价、新客年卡5折起，力度最大，限从未付费账号
- **老客可领**：续费立减券、年卡特惠、618/双11/周年庆大促券
- **新老客通用**：通用充值折扣券、联合会员礼包
- 新客优惠一个账号只用一次，建议先领券再充，别直接在App原价开通浪费名额

## 五、避坑指南

1. **"共享号/合租会员"是坑**：违规共享易被封号、盗号，别图便宜买
2. **自动续费忘了关**：首月低价后默默扣高价月费，开通后立刻关
3. **手机会员当TV会员买**：手机端会员看不了电视，想投屏/电视看要选全屏/TV会员
4. **联合会员凑单**：用不上的音乐/网盘权益别为"便宜"硬买
5. **虚拟商品不退**：会员充值到账后原则上不退不换，下单前确认账号和档位
